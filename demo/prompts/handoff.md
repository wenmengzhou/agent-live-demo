Stop working on the task. Write a handoff note to HANDOFF.md so that a different agent, starting fresh with only this note and the working tree, can finish the job.
Use exactly these sections, and keep it under 60 lines:

## Goal
The task and its acceptance criteria ("done when"), copied from the brief.

## Done so far
What you changed, file by file, and whether `npm run verify` passes right now.

## Where it's stuck
The current failure or open question, with the exact error message.

## What was tried
Each approach you tried, and why it did not work. Include theories you ruled out.

## Suggested next step
The single next thing you would do, and why.

Write facts, not the story of the session. Leave out logs unless one line of one is the evidence.
